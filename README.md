# Oltre Frutti

Catálogo online de frutas y verduras frescas a domicilio. El cliente arma el pedido en la web y lo envía por WhatsApp.

## Pedido

1. Elegí productos del catálogo
2. Completá nombre, dirección y forma de pago
3. Enviá el pedido por WhatsApp

**Envíos:** de 8:00 a 12:00 (se puede coordinar por la tarde). Zona Norte sin cargo; otras zonas se cotizan.

## Desarrollo

```bash
npm install
npm run dev
```

Build de producción:

```bash
npm run build
```
